Canvas Coach setup

Edits config.json in your private canvas-coach repo. This page stores nothing on its own. Your Canvas token is not entered here; it lives in the repo's encrypted Actions secrets.

Open report page Open dashboard

2. Reports

Times are in your time zone. Each enabled report is saved to the report page; tick Email to also send it.

3. Email

Sending uses the SMTP_USER and SMTP_PASS secrets (a Gmail address + app password).

4. Alerts

5. Courses

Full Canvas course name → what reports call it.

6. Study time

Manual windows (used only when the automatic option is off), e.g. 15:00-17:00, 19:00-21:30.

7. Important dates

Registration, bus tickets, drop deadlines, anything. You get reminders 14, 7, 3, 1 and 0 days before (or the days you list).

8. Calendar feeds (optional)

Any .ics link, like a campus events calendar. Keywords filter it (e.g. registration, bus, break).

The full config as JSON. Edits here win when you save.
